Izin API key: DataStore biasa (universe-datastores) butuh List Datastores, List Entries, Read Entry untuk ekspor, dan Create Entry, Update Entry untuk impor. Ordered DataStore memakai API system terpisah (Ordered Data Stores) dengan izin baca untuk ekspor dan tulis untuk impor. Satu key cukup kalau sumber dan tujuan milik creator / group yang sama. Batas Roblox 300 request/menit per universe dipakai bersama server game yang sedang berjalan. Hasil ekspor disimpan di browser ini (IndexedDB) dan langsung bisa diimpor tanpa diunduh. Hasil ordered bernama ordered_NAMA_SCOPE. Tombol Unduh hanya untuk cadangan: unduh sebelum menghapus data situs. Entry di atas ~3 MB tidak bisa melewati proxy.
